# M2Idle Companion – Userscript-Downloads

Offizielle Update-Dateien des unabhängigen **M2Idle Companion** für [M2Idle](https://m2idle.pl/). Nutzbar mit **Safari Userscripts** auf iPhone/iPad und **Violentmonkey** in Chromium-Browsern am PC.

## Aktuell veröffentlichte Kanäle

| Kanal | Aktuelle Version | Name im Userscript-Manager | Installation |
| --- | --- | --- | --- |
| **Stable** | **1.7.9** | `M2Idle Companion (Stable)` | [Stable installieren](https://raw.githubusercontent.com/Blacksonny/M2Idle-Companion-Updates/main/stable/M2Idle-Companion.user.js) |
| **Beta** | **1.8.9** | `M2Idle Companion (Beta)` | [Beta installieren](https://raw.githubusercontent.com/Blacksonny/M2Idle-Companion-Updates/main/beta/M2Idle-Companion.user.js) |

Die Versionsangaben werden bei **jeder erfolgreich veröffentlichten Stable- oder Beta-Ausgabe automatisch direkt aus den jeweiligen `@version`-Metadaten** aktualisiert. Die beiden Kanäle haben eigene `@updateURL`- und `@downloadURL`-Adressen.

**Nur einen Companion gleichzeitig aktivieren.** Wähle Stable oder Beta direkt im Userscript-Manager; es gibt keinen zusätzlichen Funktionsmodus im Companion. Beim Wechsel die bisherige Ausgabe deaktivieren. Nach älteren Script-Umbenennungen können doppelte Einträge zurückbleiben.

## Installation und Updates

**iPhone / iPad:** Die Safari-Erweiterung **Userscripts** aktivieren, Zugriff auf `game.m2idle.pl` erlauben, den gewünschten Kanal installieren und Updates im Manager prüfen.

**PC:** [Violentmonkey](https://violentmonkey.github.io/get-it/) installieren, den gewünschten Download öffnen und Updates mit Violentmonkey prüfen.

## Projekt

Der Companion bietet freiwillige Markt-, Preis- und Ausrüstungshilfen, keine automatischen Käufe, Verkäufe oder Ausrüstungswechsel. Keine offizielle Verbindung zum Betreiber von M2Idle; dessen Nutzungsbedingungen gelten.
